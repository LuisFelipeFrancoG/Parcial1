## Descripción

Este repositorio contiene el trabajo correspondiente al Parcial 1. Aquí se desarrollan las soluciones de los diferentes módulos del proyecto, incluyendo la implementación de áreas como "Banco" y "Pacman".

## Estructura del Proyecto

- **Banco**: Módulo encargado de la gestión de cuentas bancarias.
- **Pacman**: Módulo dedicado a la implementación del juego y sus componentes.

## Instrucciones de Uso

1. Clona el repositorio.
2. Abre el proyecto en Visual Studio Community 2022.
3. Navega a la carpeta correspondiente al módulo que desees probar.
4. Ejecuta la aplicación y sigue las instrucciones en la consola.
